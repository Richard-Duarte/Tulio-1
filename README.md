# Tulio Music

Site oficial do DJ **Tulio** — home, galeria, sets (player SoundCloud), releases, datas e presskit com senha.

**Produção**: https://www.tuliomusic.com.br

## Development

Node.js 24+ e npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

```sh
npm test
npm run build
```

This project is connected to [Lovable](https://lovable.dev). See `AGENTS.md` for git history constraints.
